# **NebulaMem v2 (Python)**

NebulaMem is a local-first, in-process long-term memory engine for AI Agents, modeled after the human brain's "spreading activation" and "lateral inhibition" mechanisms. It is designed to be lightweight, zero-dependency, and extremely fast, avoiding the heavy overhead of external database servers.

This codebase integrates the **Zvec**-inspired in-process vector model and the **LadybugDB**-inspired Cypher relationship schema using highly optimized local storage backends with zero server daemons.

## **Key Features**

- **In-Process Vector Search**: Fast semantic indexing modeled on [Alibaba Zvec](https://zvec.org/zh/) (using highly optimized NumPy matrix multiplication under the hood, with direct library bindings support).
- **Embedded Graph Topology**: Entity-relationship graph mapping modeled on [LadybugDB](https://github.com/LadybugDB/ladybug) (using an SQLite-powered relation and edge database).
- **Lateral Inhibition (侧向抑制)**: Dynamically suppresses conflicting memories (e.g., when moving from an old Python sync engine to a new Rust multi-threaded engine) through inhibitory synapses.
- **Asynchronous Consolidation**: Background memory weight decay (forgetting) and active knowledge distillation (inspired by [Andrej Karpathy's LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) compiler).

## **Installation & Setup**

1. Clone or extract the project zip package.
2. Initialize and install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## **Running Simulations & Verification**

To execute the real-world simulation demo (which maps and tests Ghostty features, Zellij layout rules, and Yiwu logistics integration APIs):
```bash
python demo.py
```

To run the robust automated unit/integration test suite:
```bash
python -m unittest discover -s tests
```

For detailed specifications regarding the underlying math, database schemas, and comparative cognitive analysis, please inspect the contents of the `docs/` folder.
